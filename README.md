A modern, responsive personal developer portfolio website presenting featured software engineering projects, technical skillsets, and professional contact channels.

---

## ✨ Features

- **Responsive Design:** Optimized presentation across desktop, tablet, and mobile browsers.
- **Featured Projects Showcase:** Deep links and overviews for top full-stack, AI/ML, and Java applications.
- **Skills Matrix:** Categorized technical competencies spanning Python, Node.js, React, Java, Docker, and AWS.
- **Direct Contact Channel:** Interactive contact form and social networking links (LinkedIn, GitHub).

---

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gopikrishna1536/My-portfolio.git
   cd My-portfolio
   ```

2. **Open directly in browser:**
   Open `index.html` in any web browser, or launch using Node.js:
   ```bash
   node server.js
   ```

3. **Deploy to Vercel:**
   ```bash
   vercel --prod
   ```
